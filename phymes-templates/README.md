## Synopsis

The PHYMES templates crate provides network components and recipes for building complex subject-based messaging passing execution networks. Templates to create simple chatbots, function calling agents, RAG agents, and coding agents are provided and will be expanded in the future. More complex templates for research and data science agents are also in progress...
