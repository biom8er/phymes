# Example: Chat

## Synopsis

This tutorial describes how the [Chat Processor](https://github.com/biom8er/phymes/blob/main/phymes-ml/src/candle_chat/chat_processor.rs) uses the [phymes-ml](https://github.com/biom8er/phymes/blob/main/phymes-ml/README.md) and [phymes-subject](https://github.com/biom8er/phymes/blob/main/phymes-subject/README.md) crates to run a text generation inference using embedded Candle assets. The `chat` executable is provided in the [examples](https://github.com/biom8er/phymes/blob/main/phymes-ml/examples/chat/main.rs).
