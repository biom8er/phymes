# Events

Events add context to enable building a comprehensive timeline of what happened, when it happened, and why it happened. Trace events record extremely fine-grained information, useful for tracing program execution. Note that a dedicated Tracing diagnostic class is provided, and the trace event here is for compatibility with external logging libraries. Debug events record detailed debugging information, typically used during development. Info events record general informational messages about the program's operation. Warn events record warnings about potential issues that are not immediately fatal. Error events critical errors that cause the program to fail or behave incorrectly. Error events are often used in conjunction with actual Errors or Panics to provide greater context to the Error or Panic when disabling RUST_BACKTRACE for verbose error output at the application level.
